# Billingsoft Restaurant SaaS

A scalable restaurant management SaaS platform with a Node.js/Express/MongoDB backend, Socket.IO real-time events, and a React/Tailwind admin UI.

## Modules

- Super Admin dashboard
- Merchant admin panel
- Captain order system
- Billing POS
- Kitchen Display System (KDS)
- QR menu website foundations
- Inventory, reports, expenses, staff, branches, tables, printers

## Quick start

```bash
cp backend/.env.example backend/.env
npm install
npm run dev
```

## Workspace scripts

```bash
npm run dev --workspace backend
npm run dev --workspace frontend
npm run lint --workspace backend
npm run lint --workspace frontend
```
